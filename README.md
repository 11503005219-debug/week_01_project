# Week 01 PHP Exercises

Full Stack Web Development. All data is fictional.

## Run

Copy this folder into the XAMPP document root (`htdocs`), start Apache, then open
`http://localhost/week01-php-exercises/exercise01/` (change the number for each exercise).

Exercise 10 has a form: pick the dataset ("Dataset with problems" shows the warnings and quality scores).

## Exercises

| # | Topic |
|---|-------|
| 01 | Fictional citizen profile (`displayProfileField()`) |
| 02 | Age classification and eligibility (`classifyCitizen()`) |
| 03 | Household member summary (`summariseMembers()`) |
| 04 | Dzongkhag service counter (dynamic counters) |
| 05 | Record search (`searchProfiles()`, case insensitive) |
| 06 | Profile validation (`validateProfile()`) |
| 07 | Service fee calculator (`calculateServiceFee()`) |
| 08 | Role permission checker (`canPerformAction()`) |
| 09 | Records report (tables and interpretation) |
| 10 | Command dashboard with data-quality score |

Each file has a comment explaining one key programming decision.
